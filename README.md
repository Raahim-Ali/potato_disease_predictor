# potato_disease_predictor
Investigating the utilization of machine learning in predicting potato crop diseases using weather parameters

The main problem addressed in this dissertation is the early prediction of potato crop diseases, specifically early blight and late blight, using weather-driven environmental parameters.

Input: Historical and real-time weather data including temperature and humidity.

Task: Determine whether the weather conditions indicate a high risk of potato crop disease, specifically early or late blight.

Output: A disease risk prediction presented through a user-friendly interface. If risk is detected, the system identifies the type of disease, enabling timely preventive action. If no risk is predicted, the system confirms that current weather conditions are safe for crops.
